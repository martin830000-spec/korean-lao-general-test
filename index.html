🌐 다국어 TEST 사용법

1. 상대 언어 선택상단의 상대 언어에서 라오어·영어·중국어(간체)·일본어·태국어 중 대화할 언어를 고릅니다.
2. 말하는 사람이 바뀔 때기존 언어전환을 누르면 선택한 두 언어의 번역 방향만 뒤집힙니다.
남편 모드에서는 내 언어가 한국어로 고정됩니다. 예: 한국어 → 영어 ⇄ 영어 → 한국어. 앱의 조작 메뉴는 계속 한국어로 표시됩니다.
화면을 보면서 따라 하기

🚀 1. 가장 쉬운 사용법

① 말하거나 입력한국어 말하기 / 라오어 말하기를 누르거나 입력창에 직접 씁니다.
② 번역하기번역하기를 누르면 상대방 언어로 바뀝니다.
③ 보여주거나 들려주기듣기로 재생하거나 크게보기로 화면을 보여줍니다.
④ 상대방 차례언어전환을 눌러 번역 방향을 바꿉니다.
대화를 더 빠르게

⚡ 2. 자동통역 · 자동 음성출력

⚡ 자동통역음성입력이 끝나면 자동으로 번역합니다. 키보드로 직접 입력한 문장은 자동번역하지 않습니다.
🔊 자동음성켜 두면 번역이 끝난 뒤 상대방 언어를 자동으로 읽어줍니다.
말하기→자동 번역→자동 재생
서로 말을 주고받을 때는 자동통역 + 자동음성을 함께 켜 두면 편합니다.

🔊 3. 듣기 · 음성 중지 · 다시 듣기

⛶ 4. 크게보기 · 180° 회전

⛶ 크게보기결과카드 오른쪽 위에서 누르면 번역문을 크게 보여줍니다.
↻ 180° 회전휴대폰을 상대방 쪽으로 놓았을 때 글자를 돌릴 수 있습니다. 닫았다 다시 열면 정방향으로 시작합니다.
헷갈리기 쉬운 버튼

🧰 5. 결과와 지우기 기능

의미확인번역문을 다시 원래 언어로 확인해 핵심 뜻이 유지됐는지 살펴봅니다.
↻ 재번역 · 📋 복사같은 원문을 다시 번역하거나 결과를 다른 앱에 붙여넣습니다.
입력 지우기입력창의 문장만 지우고 이미 나온 번역 결과는 남깁니다.
↺ 전체 지우기현재 입력과 번역 결과를 함께 비웁니다. 최근 대화 기록은 지우지 않습니다.
🕘 최근 대화에서 이전 번역을 다시 확인하거나 불러올 수 있습니다.
사용 전에 잠깐 확인

⚠️ 6. 알아두면 좋은 점

짧고 분명하게긴 문장을 반복하기보다 핵심을 1~2문장으로 나누면 이해하기 쉽습니다.
음성인식 확인소음이 있으면 말이 다르게 인식될 수 있습니다. 번역 전에 입력문을 확인하세요.
이름·주소·시간·금액사람 이름, 호텔명, 전화번호, 날짜, 시간, 가격과 주소는 다시 확인하세요.
중요한 상황의료·계약·금융·법률처럼 오해의 영향이 큰 내용은 필요하면 사람의 통역이나 추가 확인을 이용하세요.
가장 편한 방법: 자동통역 ON + 자동음성 ON · 상대방 차례에는 언어전환
