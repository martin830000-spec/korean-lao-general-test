여행과 일상에서 바로 쓰는 한국어 ↔ 라오어 통역앱

음성 또는 글로 입력하고, 자동통역을 켜면 음성인식 → 문장 최소교정 → 번역 → 상대 언어 음성출력까지 자동으로 이어집니다.

1 기본 사용
⇄언어전환한국어 ↔ 라오어
→
🎙️말하기/입력음성 또는 직접 입력
→
➤번역하기버튼 한 번
→
✅결과 확인의미확인 자동 실행
2 입력 화면과 음성입력
입력창 위 왼쪽의 🎙️ 한국어/라오어 말하기 버튼으로 음성입력을 시작합니다. 말한 뒤 같은 버튼을 다시 누르면 종료되고, 인식 처리 중 다시 누르면 취소됩니다. 오른쪽 입력 지우기는 입력문만 지웁니다.
새 음성입력이 실제로 시작되면 이전 입력문은 자동으로 비워집니다. STT 결과가 들어와도 키보드는 자동으로 열리지 않습니다.
3 자동통역 · 음성 자동교정
입력창 아래의 ⚡ 자동통역을 켜면 음성인식이 정상 완료된 뒤 자동으로 번역하고 상대 언어로 바로 읽어줍니다. 직접 타이핑한 문장은 자동 실행하지 않습니다.
말더듬·반복·문맥상 명백한 STT 오인식이 의심될 때만 보수적으로 최소 교정합니다. 숫자·시간·장소·이름·부정/긍정 등 중요한 정보는 함부로 바꾸지 않습니다.
4 하단 고정 퀵바
⚡ 자동통역ON/OFF · ແປອັດຕະໂນມັດ
⇄ 언어전환한국어 ↔ 라오어 · ສະຫຼັບພາສາ
🎙️ 말하기현재 입력 언어 음성인식
➤ 번역하기수동 번역 / 번역 중지
화면을 스크롤해도 하단바는 항상 보입니다. 모든 하단바 기능은 한국어와 라오어를 함께 표시합니다.
5 의미확인 · 자동 역번역
번역이 끝나면 결과 문장을 다시 원래 언어로 번역해 의미가 제대로 전달됐는지 확인합니다. 오른쪽에는 소요시간만 표시됩니다.
의미확인 중 버튼을 누르면 중지할 수 있고, 다시 누르면 재실행할 수 있습니다.
6 결과 사용
🔊 듣기상대 언어 음성으로 재생
📋 복사번역본 + 의미확인 2줄 복사
📱 크게 보기문장을 180° 돌려 상대방에게 바로 보여주기
🔄 재번역같은 원문을 다시 번역
7 최근 대화 · 부부대화 · 설정
최근 대화는 이 기기에 최대 50개 저장하며 제목을 눌러 펼치거나 접을 수 있습니다. 불러오기는 원문만 입력칸에 넣습니다.
💬 부부대화부부 전용 번역앱으로 이동
⚙️ 설정연결 상태·경로·진단 확인
💡 사용 팁
사람 이름, 장소, 숫자, 시간처럼 중요한 내용은 번역 결과와 의미확인을 함께 확인하면 더 안전합니다. 통역이 급할 때는 짧고 한 문장씩 말하는 것이 가장 안정적입니다.

ສາມາດເວົ້າຜ່ານໄມຄ໌ ຫຼື ພິມຂໍ້ຄວາມ. ເມື່ອເປີດ “ແປອັດຕະໂນມັດ” ແອັບຈະຮັບສຽງ → ປັບແກ້ຂໍ້ຄວາມເທົ່າທີ່ຈຳເປັນ → ແປ → ອ່ານຜົນແປເປັນສຽງອັດຕະໂນມັດ.

2 ຊ່ອງປ້ອນຂໍ້ຄວາມ ແລະ ຮັບສຽງ
ກົດປຸ່ມ 🎙️ ເວົ້າພາສາເກົາຫຼີ/ເວົ້າພາສາລາວ ທີ່ຢູ່ເທິງຊ່ອງປ້ອນເພື່ອເລີ່ມຮັບສຽງ. ເມື່ອເວົ້າຈົບ ໃຫ້ກົດປຸ່ມເດີມອີກຄັ້ງເພື່ອຢຸດ. ຖ້າກຳລັງປະມວນຜົນ ກົດອີກຄັ້ງເພື່ອຍົກເລີກ. ປຸ່ມ ລ້າງຂໍ້ຄວາມ ຈະລ້າງສະເພາະຂໍ້ຄວາມທີ່ປ້ອນ.
ເມື່ອເລີ່ມຮັບສຽງໃໝ່ສຳເລັດ ຂໍ້ຄວາມເກົ່າຈະຖືກລ້າງອັດຕະໂນມັດ. ຫຼັງຮັບສຽງແລ້ວ ແປ້ນພິມຈະບໍ່ເດັ້ງຂຶ້ນເອງ.
3 ແປອັດຕະໂນມັດ · ປັບແກ້ຄຳຈາກສຽງ
ເມື່ອເປີດ ⚡ ແປອັດຕະໂນມັດ ຫຼັງຈາກຮັບສຽງສຳເລັດ ແອັບຈະແປທັນທີ ແລະ ອ່ານຜົນແປເປັນສຽງໃຫ້ອີກຝ່າຍຟັງ. ຂໍ້ຄວາມທີ່ພິມເອງຈະບໍ່ເລີ່ມແປອັດຕະໂນມັດ.
ລະບົບຈະປັບແກ້ແຕ່ການເວົ້າຕິດຂັດ, ຄຳຊ້ຳ ຫຼື ຄຳທີ່ STT ຮັບຜິດຢ່າງຊັດເຈນ. ຕົວເລກ, ເວລາ, ສະຖານທີ່, ຊື່ ແລະ ຄວາມໝາຍປະຕິເສດ/ຢືນຢັນ ຈະບໍ່ຖືກປ່ຽນໂດຍການຄາດເດົາ.

➤ ແປແປເອງ / ຢຸດການແປ
ແຖບນີ້ຈະສະແດງຢູ່ລຸ່ມຈໍຕະຫຼອດເຖິງແມ່ນຈະເລື່ອນໜ້າຈໍ. ທຸກປຸ່ມສະແດງທັງພາສາເກົາຫຼີ ແລະ ພາສາລາວ.
5 ກວດຄວາມໝາຍ · ແປກັບອັດຕະໂນມັດ
ຫຼັງຈາກແປແລ້ວ ແອັບຈະແປຜົນກັບໄປຫາພາສາເດີມເພື່ອຊ່ວຍກວດວ່າ ຄວາມໝາຍຖືກສົ່ງຄົບຫຼືບໍ່. ດ້ານຂວາສະແດງສະເພາະເວລາທີ່ໃຊ້.
ໃນຂະນະກຳລັງກວດ ສາມາດກົດປຸ່ມເພື່ອຢຸດ ແລະ ກົດອີກຄັ້ງເພື່ອກວດໃໝ່.

7 ປະຫວັດລ່າສຸດ · ສົນທະນາຄູ່ສົມລົດ · ຕັ້ງຄ່າ
ແອັບເກັບປະຫວັດໄດ້ສູງສຸດ 50 ລາຍການໃນເຄື່ອງນີ້. ກົດຫົວຂໍ້ “ປະຫວັດລ່າສຸດ” ເພື່ອເປີດ/ພັບລາຍການ. ປຸ່ມ ເອີ້ນຄືນ ຈະນຳສະເພາະຂໍ້ຄວາມຕົ້ນສະບັບກັບມາໃສ່ຊ່ອງປ້ອນ.
